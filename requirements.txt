# PySpark drives the DQ engine's bulk table processing (data sources, profiling, rule
# validation, staging/DB read-write). It embeds a JVM, so a Java 17 runtime (JAVA_HOME set,
# java on PATH) is required wherever this runs - pip alone is not enough. Database/BigQuery
# JDBC connector jars are resolved from Maven Central at Spark session startup (see
# backend/engine/core/spark_session.py's _JDBC_PACKAGES), not bundled here.
#
# Pinned exactly to 3.5.1 (Scala 2.12) rather than left open-ended: 4.x (Scala 2.13) hit an
# open, unfixed upstream bug on Windows - SPARK-53042, "BlockExecutor ID is null randomly
# using Windows OS and Java 17" - that intermittently breaks executor heartbeats. 3.5.1 is
# the long-established, stable line; _JDBC_PACKAGES' BigQuery connector coordinate must stay
# matched to whichever Scala build is in use (the `_2.12` in its artifact id).
